# 読書録

個人用の読書記録アプリ（インストール型ウェブアプリ）の公開用ファイルです。

- 公開ページ：https://iggyh.github.io/dokusho/
- 本や感想などのデータは、利用者自身の Google スプレッドシート（Google Apps Script の窓口）に保存されます。このリポジトリにはデータも合言葉も含まれません。
- このリポジトリのファイルは、改修のたびに Claude が更新します。直接編集しないでください。
- バーコードの読み取り部品（barcode-reader.js・zxing_reader.wasm）は zxing-wasm（MIT License）と ZXing-C++（Apache License 2.0）です。ライセンスの全文は barcode-reader.js の先頭にあります。
